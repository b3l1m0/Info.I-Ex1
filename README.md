# Info.I-Ex2
C++ scripts for Exercise 2 of the Informatik I Lecture of the first semester of my B.Sc. Chemical Engineering


ex2A: small C++ program relying on the ideal-gas law that writes a table of values for the pressure of one mole of gas as a function of its volume at a given reference temperature 


ex2B: small C++ program that samples P(V) for a set of successive values of V at a given T_ref, but relying on either the ideal-gas law or on the real-gas law of van der Waals (choice given to the user)


ex2C: a small C++ program that “carries out” a Stirling cycle (four legs involving successive small variations of V or T), and calculates its thermal yield
